About PepPCDB

Features And Sequence Annotation Rules

Portal-level notes for browsing, structure display, and interface annotation semantics.

Features

  • Prebuilt SQLite index for the PDB-derived `filtered_peppi` peptide-protein complex dataset.
  • Search and filter entries by PDB ID, cluster ID, peptide chain, sequence fragment, non-standard residues, cyclic status, and affinity availability.
  • Function Annotation & Affinity view linking peptide ligands to protein target cards, functional roles, curated notes, and normalized affinity values.
  • Peptide annotation view covering sequence, chain length, non-standard modifications, cyclic topology, nonpoly components, and covalent/connect records.
  • Interface view with pair classification (`PepPI` / `PPI` / `other`), contact masks, secondary-structure coloring, and sequence-embedded markers.
  • 3D structure view with RCSB preview, Mol* launch, mmCIF download, entry ZIP download, and generated function JSON download.

Legend Details

In Interface view, markers are embedded directly on residue characters.

Marker Meaning Render Rule
A MASK contact residue Character boxed if mask position is `-`.
A SS = H (Helix) Text color by secondary structure class.
A SS = E (Beta) Text color by secondary structure class.
A SS = C (Coil) Text color by secondary structure class.
A NONSTD MOD Dotted underline and hover tooltip with mod type + position.

Quick Download API

The public API surface is limited to quick download endpoints. Browser search and detail endpoints are internal page APIs.

Endpoint Output File Naming
GET /api/download/{entry_key}.zip All source files for one entry. {pdb_id}.zip
GET /api/download/{entry_key}/{pdb_id}.cif mmCIF coordinate file for one entry. {pdb_id}.cif
GET /api/download/{entry_key}/{pdb_id}_annotations.json Peptide chain annotations, including non-standard residue and cyclic metadata. {pdb_id}_annotations.json
GET /api/download/{entry_key}/{pdb_id}_interface.jsonl Pair-level interface records for one entry. {pdb_id}_interface.jsonl
GET /api/download/{entry_key}/{pdb_id}_function.json Generated 2-space JSON merging peptide function annotations, affinity values, target tags, and linked target-card records. {pdb_id}_function.json

Download API requests are limited to 100 requests per client IP per hour.
