PepPCDB: A PDB-wide Database of Peptide-Protein Complexes with Structural and Functional Annotations

A curated PDB-derived atlas linking peptide chains, protein targets, interfaces, biological functions, and affinity values.

What PepPCDB Provides

PepPCDB organizes peptide-protein complexes from PDB structures into a browsable atlas with peptide chain metadata, interface records, target cards, function annotation, and affinity links.

Structural Context

Browse entries by PDB ID, sequence fragment, non-standard residue status, cyclic topology, and peptide-protein interface count, then inspect annotations and local 3D structure views.

Function & Affinity Annotation

Curated peptide records connect ligand chains to protein target axes, functional mechanisms, supporting notes, and normalized affinity values when reliable evidence is available.

Features

  • Prebuilt SQLite index for the current PDB-derived filtered_peppi peptide-protein complex release.
  • Search and filter entries by PDB ID, cluster ID, peptide chain, sequence fragment, non-standard residues, cyclic status, and affinity availability.
  • Function Annotation & Affinity view linking peptide ligands to protein target cards, functional roles, curated notes, and normalized affinity values.
  • Peptide annotation view covering sequence, chain length, non-standard modifications, linker metadata, cyclic topology, nonpoly components, and covalent/connect records.
  • Interface view with pair classification (PepPI / PPI / other), while summary statistics and entry sorting highlight peptide-protein (PepPI) interfaces.
  • 3D structure view with local Mol* rendering from mmCIF, mmCIF download, entry ZIP download, and generated function JSON download.
